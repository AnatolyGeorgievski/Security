21 октября 2026. flood — пачка потоков в один отрезок. `flood_new` считает, сколько потоков увидели первую запись.
food — еда для этих потоков. Реакция кормит атакующего. Сигналы кормят сервис.

## Сложение

Слово — `volatile int`. Сложение — `atomic_fetch_add(&flood_new, 1)`. Обнуление — `atomic_store`, чтение — `atomic_load`.

`flood_new += 1` — другая операция. Её asm к этому счётчику не относится.

`volatile` и `_Atomic` при этих трёх вызовах дают один и тот же текст. gcc 15.2.0, `-O3`.

## x86_64

`-march=native`. Сложение:

```
lock incl flood_new(%rip)
```

Обнуление: `xorl %eax, %eax` и `xchgl flood_new(%rip), %eax`. Чтение: `movl flood_new(%rip), %eax`.

## aarch64

`aarch64-linux-gnu-gcc -march=armv8-a`. Сложение уходит в общую функцию:

```
bl __aarch64_ldadd4_acq_rel
```

Обнуление: `stlr wzr, [x0]`. Чтение: `ldar w0, [x0]`.

С `-march=armv8-a+lse` сложение встроено:

```
ldaddal w1, w1, [x0]
```

С `-mno-outline-atomics` сложение — цикл:

```
ldaxr w2, [x0]
add w2, w2, 1
stlxr w1, w2, [x0]
cbnz w1, .L
```

Обнуление и чтение те же: `stlr` и `ldar`.
