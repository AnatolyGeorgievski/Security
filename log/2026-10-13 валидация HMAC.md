# Валидация HMAC

Дата: 2026-10-13. Прогон векторов из `src/hmac.c` (`TEST_HMAC`). Цель сборки отдельная: `make hmac` в каталоге Security. В `make all` она не входит.

Бинарник `./hmac` и объект `src/gosthash.o` — продукты сборки, `make clean` их удаляет.

## Как прогнать

```sh
cd Security
make hmac
./hmac
```

Последняя строка этого прогона: `skip 0 fail 0 pass 96`. Код выхода 0. `skip` — алгоритм не собран, `fail` — сумма не совпала, `pass` — совпала.

SHA-224 берётся из `src/sha.c`. В том же файле свои SHA-1 и SHA-256, поэтому в эту цель не входят `src/sha1.c` и объект SHA-256 из `libr3`. Заголовок сборки gpg (`src/gpg_build.h`) к тесту не подключается: он подменяет `_aligned_malloc`, и `r3_slice.c` тогда не компилируется. Демонстрационный `main` в `src/gosthash.c` собирается как `gosthash_demo`.

Векторы в файле ссылаются на FIPS 198-1, RFC 4231, RFC 4868, RFC 5869, RFC 6070, RFC 6234, RFC 6986, RFC 7836 и документы ТК 26 (Р 50.1.111-2016, Р 50.1.113-2016). Случай PBKDF2 на 16 777 216 итераций в исходнике закомментирован и в счёт 96 не входит.
